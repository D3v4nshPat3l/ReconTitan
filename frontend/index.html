☣ Danger Mode — authorized testing only

Danger Mode sends bounded penetration-test simulation traffic: injection probes, directory and traversal fuzzing, identifier enumeration, and DNS zone-transfer attempts.

  • Nothing on the target is created, modified, or deleted.
  • No credentials are used against live accounts.
  • No reverse shell is ever connected — command-injection vectors are reported only.
  • Secrets, tokens, and object contents are fingerprinted, never stored.
  • Every result is a candidate requiring manual validation.
  • Expect 3–6 minutes. The scan is capped by a wall-clock limit; if it is hit, remaining stages are skipped and the report is still produced from completed work.

Danger Mode is locked.

Authorization required. Scan only systems you own or have explicit written permission to assess. Private and non-routable targets are blocked by default.
